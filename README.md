# 厚生局届出情報 自動巡回＆特定施設抽出ツール

全国の地方厚生局ウェブサイトを自動巡回し、「新規・変更」「辞退」の届出情報（PDF）の新着を検知・ダウンロードして、自院（特定の施設名）に関する情報が含まれるページだけをピンポイントで抽出する実務自動化ツールです。

**設定した地区の厚生局のホームページより、**
1. `Downloaded_PDFs` フォルダに、当該県の受理通知一覧をダウンロード
2. `Extracted_Pages` フォルダに、①からキーワード（施設名等）が含まれるページのみを別途再抽出

することができるツールです。

---

## 💡 主な機能
1. **新着自動検知**: 過去に処理したPDFのリンクを保持し、更新があった場合のみ作動（無駄なダウンロードを防ぎます）。ダウンロードや抽出に失敗した場合は「未処理」のまま記録し、次回実行時に自動リトライします（見落とし防止）。
2. **日付取得とリネーム**: 厚生局ごとの不規則なHTMLタグ構造や文字の分断に惑わされず、ページ内の文字を全結合して最新の処理日付（和暦）を確実に取得し、ファイル名に反映します。
3. **複数プロファイル対応**: 1つの `config.ini` に「施設 × 施設種別」の組み合わせを何件でも登録でき、1回の実行で順番にすべてチェックします（自施設と比較したいライバル病院を別プロファイルとして並行監視、なども可能）。ダウンロードPDF・抜粋PDF・更新チェック記録はプロファイルごとにフォルダ分けされるので混ざりません。1件のプロファイルでエラーが起きても、そこだけスキップして残りは続行します。
4. **かんたん設定 (setup.py)**: プロファイルの追加・編集・削除、タスクスケジューラ登録（実行時刻も指定可）がGUIで直感的に行えます。
5. **実行ログ**: 実行のたびに `logs/update_history_YYYYMM.txt` へ、日時・プロファイルごとの結果（更新あり／なし／エラー）を追記します。あとから「ちゃんと動いていたか」を確認できます。
6. **インテリジェント自爆バッチ**: 
   - 正常終了時：ログ表示後、**10秒**で自動クローズ
   - エラー発生時：ログ確認のため、**60秒**保持した後に自動クローズ

## 🛠 動作環境・準備
- **言語**: Python 3.13+
- **環境管理**: `uv` (高速パッケージマネージャー)

### 持ち運ぶべき必須ファイル (Git管理対象)
家や別のPCで開発・実行を引き継ぐ際は、`config.ini`・`state/`・`Downloaded_PDFs/`・`Extracted_Pages/` 以外の
ソースファイル一式（`*.py`, `kouseikyoku_patterns/`, `pyproject.toml`, `uv.lock`, `*.bat` など）を移動させてください。

> ⚠️ **注意 (`.gitignore` 推奨対象・設定済み)**
> セキュリティおよびデータ肥大化防止のため、以下はGitに含めないでください（`.gitignore`済み）。
> - `config.ini` (自院名などの秘匿情報が含まれるため。ファイル自体に設定項目の説明コメントが自動で入るので、テンプレートファイルは別途用意していません)
> - `.venv/` (ローカル仮想環境)
> - `state/` (プロファイルごとの更新チェック記録。旧 `previous_link_*.txt`)
> - `Downloaded_PDFs/`, `Extracted_Pages/` (ダウンロード・抜粋データ。プロファイルごとにサブフォルダ分け)

## 🚀 使い方 (環境再現〜実行まで)

### 1. 環境の再構築（初回・別PC移行時）
プロジェクトフォルダを開き、ターミナルで以下を実行します。
```bash
uv sync
```
必要なパッケージ（requests / beautifulsoup4 / pdfplumber / pypdf 等）が自動的にインストールされます。

### 2. プロファイルを設定する
`config.ini` が無い状態で実行すると、自動的に設定画面（`setup.py`）が開きます。手動で開きたい場合は次を実行してください。
```bash
uv run setup.py
```
画面左側が登録済みプロファイルの一覧、右側が編集フォームです。

1. 「新規追加」をクリック
2. 都道府県を選択する（マスターデータ `bureau_master.py` から厚生局名・URL・サイト構造パターンが自動反映されます）
3. 検索キーワード（自院名。比較したい病院名でも可。カンマ区切りでAND指定）を入力
4. 対象PDF（医科／歯科／薬局／訪問看護）と対象カテゴリ（新規・変更／辞退）を選択
5. プロファイル名は「都道府県_施設種別」の形で自動提案されますが、自由に変更できます（例:「〇〇病院_医科」「△△病院_医科」「□□歯科_歯科」のように名前を分ければ、同じ都道府県・施設種別でも何件でも並行登録できます）
6. 「このプロファイルを保存」

監視したい施設・施設種別の数だけ、同じ要領でプロファイルを追加してください。

### 3. 実行する
用途に応じて3通りの実行方法があります。

| 方法 | 説明 |
|---|---|
| `run_check_all.bat` をダブルクリック | **全プロファイル**を順番にチェック（手動での全件チェック向け。定期自動実行は下記のタスクスケジューラ登録を使用） |
| `run_check_pick.bat` をダブルクリック | 番号を選んで**1つのプロファイルだけ**チェック（動作確認・単発チェック向け） |
| `uv run main.py [オプション]` | ターミナルから直接実行 |

`main.py` のコマンドラインオプション:
- 省略時: 全プロファイルを実行
- `--profile "プロファイル名"` / `-p`: 指定したプロファイルだけ実行
- `--pick` / `-i`: 対話形式で番号を選んで実行（`0`を選ぶと全件実行）
- `--list` / `-l`: 登録済みプロファイル名の一覧を表示するだけ（実行はしない）
- `--batch` / `-b`: 無人実行向けのバッチモード。設定不足時にダイアログを出さず、結果報告ポップアップも出さずにエラーとして即終了する（タスクスケジューラ用。手動実行では基本的に不要）

### 4. タスクスケジューラに登録する（定期自動実行）
`setup.py` の「実行時刻」欄（HH:MM形式、初期値 `09:00`）を好きな時刻に変更してから「タスクスケジューラ登録」ボタンを押すと、Windowsのタスクスケジューラにその時刻で毎日実行されるタスク（`AcceptanceRadarCheck`）が登録されます（既存タスクがあれば上書き）。登録されるコマンドは `uv run main.py --batch`（＝全プロファイルを1回の実行でまとめてチェックし、無人実行向けにダイアログを一切出さない）です。時刻を変更して再度ボタンを押せば、同じタスクの実行時刻だけ更新されます。

特定のプロファイルだけ別スケジュールで動かしたい場合は、Windows標準の「タスクスケジューラ」アプリを直接開き、操作に `uv run main.py --profile "プロファイル名" --batch` を指定したタスクを手動で追加してください。

> 💡 **`config.ini` のプロファイルが0件の状態でスケジュール実行時刻を迎えた場合**
> `--batch` 付きで登録されているため、設定画面を開こうとせず、エラーメッセージを出して即座に終了します（`logs/update_history_YYYYMM.txt` にも記録されます）。configをリセットした場合は、気づいたときにプロファイルを再設定してください。

> 💡 **通信エラーやPDF処理の失敗があった場合**
> ページ取得・PDFダウンロードにはタイムアウト（30秒）を設定してあるので、厚生局サーバーの応答が無くても無期限に待ち続けることはありません。また、更新を検知したのにダウンロードやページ抽出に失敗した場合は「未処理」のまま記録され、次回実行時に自動的に再試行されます（見落としの防止）。

### 5. （参考）タスクスケジューラを手動で設定する場合
`setup.py` のボタンを使わず、自分でタスクスケジューラに登録したい場合は、次のいずれかの方法で設定できます。

**方法A: タスクスケジューラのGUIで作成**
1. Windowsの検索から「タスクスケジューラ」を開く
2. 右側の「基本タスクの作成」をクリック
3. 名前: 任意（例: `AcceptanceRadarCheck`）
4. トリガー: 「毎日」を選択し、実行時刻を指定
5. 操作: 「プログラムの開始」を選択
   - プログラム/スクリプト: `cmd.exe`
   - 引数の追加: `/c "cd /d "プロジェクトのフルパス" && uv run main.py --batch"`
6. 完了

**方法B: コマンドプロンプトから直接登録**
プロジェクトフォルダで、管理者権限不要のコマンドプロンプトから次を実行します（`09:00` の部分は好きな時刻に変更してください）。
```bat
schtasks /Create /TN "AcceptanceRadarCheck" /TR "cmd /c \"cd /d %CD% && uv run main.py --batch\"" /SC DAILY /ST 09:00 /F
```
`/F` を付けているので、同名タスクが既にあれば上書きされます（重複登録の心配はありません）。特定プロファイルだけを対象にしたい場合は、`uv run main.py --batch` の部分を `uv run main.py --profile \"プロファイル名\" --batch` に置き換えてください。無人実行させる場合は `--batch` を必ず付けてください（ダイアログで固まるのを防ぐため）。

## 🗺 対応地域とサイト構造パターン
地方厚生局ごとにウェブサイトの構造がバラバラなため、`kouseikyoku_patterns/` 以下にサイト構造ごとの解析ロジック（A〜H）を分けて実装しています。都道府県ごとの対応状況・使用パターンの詳細は `bureau_master.py` の `PREFECTURE_ENTRIES` を参照してください。

| パターン | 地域 | 構造の特徴 |
|---|---|---|
| A | 関東信越・九州 | 表内のカテゴリセルから抽出 |
| B | 近畿 | 施設種別ごとにセクションが分かれ、都道府県が列、1セル内に2カテゴリが縦に並ぶ |
| C | 北海道 | 入口ページ → カテゴリ別ページを辿る |
| D | 東北 | 1ページ内、都道府県別の行がカテゴリでグループ化 |
| E | 四国（四国厚生支局） | カテゴリ × 施設種別の組み合わせごとに別ページ |
| F | 東海北陸 | 施設種別ごとにセクションが分かれ、都道府県が列 |
| G | 中国（中国四国厚生局） | 都道府県ごとにセクションが分かれ、カテゴリはセル内テキストに埋め込み |
