# 厚生局届出情報 自動巡回＆特定施設抽出ツール【acceptance-radar】

全国の地方厚生局ウェブサイトを自動巡回し、「新規・変更」「辞退」の届出情報（PDF）の新着を検知・ダウンロードして、自院（特定の施設名）に関する情報が含まれるページだけをピンポイントで抽出する実務自動化ツールです。

**設定した地区の厚生局のホームページより、**
1. `Downloaded_PDFs` フォルダに、当該県の受理通知一覧をダウンロード
2. `Extracted_Pages` フォルダに、①からキーワード（施設名等）が含まれるページのみを別途再抽出

することができるツールです。

## 📦 梱包されている各ファイルの概要

### 使う人が直接触るファイル
| ファイル | 役割 |
|---|---|
| `run_check_all.bat` | ダブルクリックで**全プロファイル**をまとめてチェック（手動実行用） |
| `run_check_pick.bat` | ダブルクリックで**プロファイルを選んで**チェック（1件だけなら自動でそれを実行） |
| `setup.py` | 設定画面（GUI）。監視する施設の登録・編集・削除、自動実行の登録／解除 |
| `main.py` | 実行本体。バッチから呼ばれるほか、ターミナルから直接実行も可能 |

### 中身のプログラム（通常は触りません）
| ファイル | 役割 |
|---|---|
| `check_kouseikyoku.py` | チェック処理の中核。更新検知 → PDF取得 → ページ抽出の流れを制御 |
| `pdf_processing.py` | PDFのダウンロードと、キーワード該当ページの抽出 |
| `pdf_facility_type.py` | 施設種別（医科／歯科／薬局／訪問看護）と PDFリンクの対応判定 |
| `bureau_master.py` | 全47都道府県の厚生局マスター（URL・サイト構造パターンの一覧） |
| `kouseikyoku_patterns/` | 厚生局サイトの構造パターン別（A〜G）の解析ロジック一式 |
| `config_loader.py` | 設定ファイル（`config.ini`）の読み書き |
| `config_setup_flow.py` | 設定が無い／不足しているときに `setup.py` へ誘導する処理 |
| `pdf_to_csv.py` | （補助）抽出済みPDFをCSVに変換する単体ユーティリティ。本体の処理には関与しません |
| `pyproject.toml` / `uv.lock` | 必要パッケージの定義（環境再現用） |
| `LICENSE` | ライセンス（MIT） |

### 実行すると自動的に作られるもの（配布物には含まれません）
| 名前 | 内容 |
|---|---|
| `config.ini` | あなたの設定（施設名など）。**個人情報を含むため他人に渡さないでください** |
| `Downloaded_PDFs/` | ダウンロードした受理通知PDF（プロファイルごとにフォルダ分け） |
| `Extracted_Pages/` | キーワード該当ページだけを抜き出したPDF（同上） |
| `state/` | 「前回どこまで確認したか」の記録。更新の有無判定に使います |
| `logs/` | 実行日時と結果（更新あり／なし／エラー）の記録 |

## 🚀 使い方

### 1. Python / uv のインストール
- **Python 3.13 以降** … [python.org](https://www.python.org/downloads/) からインストール
- **uv**（高速パッケージマネージャー）… PowerShell で次を実行するとインストールできます
  ```powershell
  powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
  ```
  （インストール方法の詳細は [uv公式](https://docs.astral.sh/uv/) を参照）

### 2. このスクリプトの使用環境の設定

**(a) 必要パッケージの取り込み**
プロジェクトフォルダを開き、ターミナルで次を実行します。requests / beautifulsoup4 / pdfplumber / pypdf 等が自動でそろいます。
```bash
uv sync
```

**(b) 監視する施設の登録**
設定画面を開きます（`config.ini` が無い状態で実行すると自動でも開きます）。
```bash
uv run setup.py
```
画面左が登録済みプロファイルの一覧、右が編集フォームです。

1. 「新規追加」をクリック
2. **都道府県**を選択（厚生局名・URL・サイト構造は自動反映されます）
3. **検索キーワード**（自院名など。カンマ区切りで複数語のAND指定も可）を入力
4. **対象PDF**（医科／歯科／薬局／訪問看護）と**対象カテゴリ**（新規・変更／辞退）を選択
5. **プロファイル名**は「都道府県_施設種別」で自動提案されますが、自由に変更できます
   （例:「〇〇病院_医科」「△△病院_医科」「□□歯科_歯科」のように名前を分ければ、同じ都道府県でも何件でも並行登録できます）
6. 「このプロファイルを保存」

監視したい施設・施設種別の数だけ、同じ要領で追加してください。

### 3. 実運用（手動で実行する）
| 方法 | 説明 |
|---|---|
| `run_check_all.bat` をダブルクリック | **全プロファイル**を順番にチェック |
| `run_check_pick.bat` をダブルクリック | **プロファイルを選んで**チェック（登録が1件だけなら自動でそれを実行、0件なら設定画面へ誘導） |
| `uv run main.py` | ターミナルから全プロファイルを実行 |

ターミナルから使う場合のオプション:
- `--profile "プロファイル名"` … 指定した1件だけ実行
- `--pick` … 対話形式で番号を選んで実行
- `--list` … 登録済みプロファイル名の一覧を表示（実行はしない）

実行すると、新着があった施設は `Extracted_Pages/` に該当ページPDFが保存されます。結果は `logs/` にも記録されます。

### 4. 実運用（自動実行・毎日決まった時刻に）
`setup.py` の画面下部「定期自動実行（タスクスケジューラ）」で設定します。

- **登録する**: チェックを入れて実行時刻（例 `09:00`）を入力し「この自動実行の設定を適用」を押す
  → Windowsのタスクスケジューラに、毎日その時刻で全プロファイルを自動チェックするタスクが登録されます
- **登録しない／解除する**: チェックを外して「適用」を押す → 登録済みの自動実行が解除されます（自動実行を使わない運用も可能）

> 💡 自動実行は無人で動くため、通信エラーやPDF取得失敗があっても画面で固まらない設計です。失敗した更新は「未処理」として記録され、次回実行時に自動で再取得を試みます（見落とし防止）。

## 🗺 対応地域とサイト構造パターン
地方厚生局ごとにサイト構造が異なるため、`kouseikyoku_patterns/` にパターン別（A〜G）の解析ロジックを実装しています。都道府県ごとの対応状況は `bureau_master.py` を参照してください。

| パターン | 地域 | 構造の特徴 |
|---|---|---|
| A | 関東信越・九州 | 表内のカテゴリセルから抽出 |
| B | 近畿 | 施設種別ごとにセクションが分かれ、都道府県が列、1セル内に2カテゴリが縦に並ぶ |
| C | 北海道 | 入口ページ → カテゴリ別ページを辿る |
| D | 東北 | 1ページ内、都道府県別の行がカテゴリでグループ化 |
| E | 四国（四国厚生支局） | カテゴリ × 施設種別の組み合わせごとに別ページ |
| F | 東海北陸 | 施設種別ごとにセクションが分かれ、都道府県が列 |
| G | 中国（中国四国厚生局） | 都道府県ごとにセクションが分かれ、カテゴリはセル内テキストに埋め込み |
