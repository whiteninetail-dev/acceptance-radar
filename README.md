# 厚生局届出情報 自動巡回＆特定施設抽出ツール (ALL JAPAN対応版＠テスト版)

全国の地方厚生局ウェブサイトを自動巡回し、「新規・変更」「辞退」の届出情報（PDF）の新着を検知・ダウンロードして、自院（特定の施設名）に関する情報が含まれるページだけをピンポイントで抽出する実務自動化ツールです。
## 注意　
現在、**全47都道府県に対応**しています（関東信越・九州・北海道・中国四国（中国地方／四国厚生支局）・東北・東海北陸・近畿）。
実運用前に、各厚生局のPDF内容が想定通り抽出できているか一度目視確認することを推奨します。
※ 中国地方は「中国四国厚生局」に統合されたため、旧 chugoku/ 配下のURLは廃止されています（chugokushikoku/ に変更済み）。
※ 福井県は地理的には東海北陸寄りに見えるが、管轄は近畿厚生局。

---

## 💡 主な機能
1. **新着自動検知**: 過去に処理したPDFのリンクを保持し、更新があった場合のみ作動（無駄なダウンロードを防ぎます）。
2. **日付取得とリネーム**: 厚生局ごとの不規則なHTMLタグ構造や文字の分断に惑わされず、ページ内の文字を全結合して最新の処理日付（和暦）を確実に取得し、ファイル名に反映します。
3. **複数プロファイル対応**: 1つの `config.ini` に「施設 × 施設種別」の組み合わせを何件でも登録でき、1回の実行で順番にすべてチェックします（自施設と比較したいライバル病院を別プロファイルとして並行監視、なども可能）。ダウンロードPDF・抜粋PDF・更新チェック記録はプロファイルごとにフォルダ分けされるので混ざりません。1件のプロファイルでエラーが起きても、そこだけスキップして残りは続行します。
4. **かんたん設定 (setup.py)**: プロファイルの追加・編集・削除、タスクスケジューラ登録がGUIで直感的に行えます。
5. **インテリジェント自爆バッチ**: 
   - 正常終了時：ログ表示後、**10秒**で自動クローズ
   - エラー発生時：ログ確認のため、**60秒**保持した後に自動クローズ

## 🛠 動作環境・準備
- **言語**: Python 3.13+
- **環境管理**: `uv` (高速パッケージマネージャー)

### 持ち運ぶべき必須ファイル (Git管理対象)
家や別のPCで開発・実行を引き継ぐ際は、`config.ini`・`state/`・`Downloaded_PDFs/`・`Extracted_Pages/` 以外の
ソースファイル一式（`*.py`, `kouseikyoku_patterns/`, `pyproject.toml`, `uv.lock`, `*.bat` など）を移動させてください。

> ⚠️ **注意 (`.gitignore` 推奨対象・設定済み)**
> セキュリティおよびデータ肥大化防止のため、以下はGitに含めないでください（`.gitignore`済み）。
> - `config.ini` (自院名などの秘匿情報が含まれるため。`config.ini.example` はテンプレートなので対象外)
> - `.venv/` (ローカル仮想環境)
> - `state/` (プロファイルごとの更新チェック記録。旧 `previous_link_*.txt`)
> - `Downloaded_PDFs/`, `Extracted_Pages/` (ダウンロード・抜粋データ。プロファイルごとにサブフォルダ分け)

## 🚀 使い方 (環境再現〜実行まで)

### 1. 環境の再構築（初回・別PC移行時）
プロジェクトフォルダを開き、ターミナルで以下を実行します。
```bash
uv sync
```
必要なパッケージ（requests / beautifulsoup4 / pdfplumber / pypdf 等）が自動的にインストールされます。

### 2. プロファイルを設定する
`config.ini` が無い状態で実行すると、自動的に設定画面（`setup.py`）が開きます。手動で開きたい場合は次を実行してください。
```bash
uv run setup.py
```
画面左側が登録済みプロファイルの一覧、右側が編集フォームです。

1. 「新規追加」をクリック
2. 都道府県を選択する（マスターデータ `bureau_master.py` から厚生局名・URL・サイト構造パターンが自動反映されます）
3. 検索キーワード（自院名。比較したい病院名でも可。カンマ区切りでAND指定）を入力
4. 対象PDF（医科／歯科／薬局／訪問看護）と対象カテゴリ（新規・変更／辞退）を選択
5. プロファイル名は「都道府県_施設種別」の形で自動提案されますが、自由に変更できます（例:「春日部中央_医科」「ライバルA_医科」のように名前を分ければ、同じ都道府県・施設種別でも何件でも並行登録できます）
6. 「このプロファイルを保存」

監視したい施設・施設種別の数だけ、同じ要領でプロファイルを追加してください。

### 3. 実行する
用途に応じて3通りの実行方法があります。

| 方法 | 説明 |
|---|---|
| `run_check_all.bat` をダブルクリック | **全プロファイル**を順番にチェック（通常運用・タスクスケジューラ向け） |
| `run_check_pick.bat` をダブルクリック | 番号を選んで**1つのプロファイルだけ**チェック（動作確認・単発チェック向け） |
| `uv run main.py [オプション]` | ターミナルから直接実行 |

`main.py` のコマンドラインオプション:
- 省略時: 全プロファイルを実行
- `--profile "プロファイル名"` / `-p`: 指定したプロファイルだけ実行
- `--pick` / `-i`: 対話形式で番号を選んで実行（`0`を選ぶと全件実行）
- `--list` / `-l`: 登録済みプロファイル名の一覧を表示するだけ（実行はしない）

### 4. タスクスケジューラに登録する（定期自動実行）
`setup.py` の「タスクスケジューラ登録（全プロファイル共通）」ボタンを押すと、Windowsのタスクスケジューラに毎日9:00実行のタスク（`AcceptanceRadarCheck`）が登録されます（既存タスクがあれば上書き）。登録されるコマンドは `uv run main.py`（＝全プロファイルを1回の実行でまとめてチェック）です。

特定のプロファイルだけ別スケジュールで動かしたい場合は、Windows標準の「タスクスケジューラ」アプリを直接開き、操作に `uv run main.py --profile "プロファイル名"` を指定したタスクを手動で追加してください。

## 🗺 対応地域とサイト構造パターン
地方厚生局ごとにウェブサイトの構造がバラバラなため、`kouseikyoku_patterns/` 以下にサイト構造ごとの解析ロジック（A〜H）を分けて実装しています。都道府県ごとの対応状況・使用パターンの詳細は `bureau_master.py` の `PREFECTURE_ENTRIES` を参照してください。

| パターン | 地域 | 構造の特徴 |
|---|---|---|
| A | 関東信越・九州 | 表内のカテゴリセルから抽出 |
| C | 北海道 | 入口ページ → カテゴリ別ページを辿る |
| D | 東北 | 1ページ内、都道府県別の行がカテゴリでグループ化 |
| E | 四国（四国厚生支局） | カテゴリ × 施設種別の組み合わせごとに別ページ |
| F | 東海北陸 | 施設種別ごとにセクションが分かれ、都道府県が列 |
| G | 中国（中国四国厚生局） | 都道府県ごとにセクションが分かれ、カテゴリはセル内テキストに埋め込み |
| H | 近畿 | 施設種別ごとにセクションが分かれ、都道府県が列、1セル内に2カテゴリが縦に並ぶ |
