# 厚生局届出情報 自動巡回＆特定施設抽出ツール (ALL JAPAN対応版＠テスト版)

全国の地方厚生局ウェブサイトを自動巡回し、「新規・変更」「辞退」の届出情報（PDF）の新着を検知・ダウンロードして、自院（特定の施設名）に関する情報が含まれるページだけをピンポイントで抽出する実務自動化ツールです。
## 注意　
現在、**全47都道府県に対応**しています（関東信越・九州・北海道・中国四国（中国地方／四国厚生支局）・東北・東海北陸・近畿）。
実運用前に、各厚生局のPDF内容が想定通り抽出できているか一度目視確認することを推奨します。
※ 中国地方は「中国四国厚生局」に統合されたため、旧 chugoku/ 配下のURLは廃止されています（chugokushikoku/ に変更済み）。
※ 福井県は地理的には東海北陸寄りに見えるが、管轄は近畿厚生局。

---

## 💡 主な機能
1. **新着自動検知**: 過去に処理したPDFのリンクを保持し、更新があった場合のみ作動（無駄なダウンロードを防ぎます）。
2. **日付取得とリネーム**: 厚生局ごとの不規則なHTMLタグ構造や文字の分断に惑わされず、ページ内の文字を全結合して最新の処理日付（和暦）を確実に取得し、ファイル名に反映します。
3. **かんたん初期設定 (setup.py)**: タスクスケジューラ登録、キーワード設定、対象都道府県の選択がGUIで直感的に行えます。
4. **インテリジェント自爆バッチ**: 
   - 正常終了時：ログ表示後、**10秒**で自動クローズ
   - エラー発生時：ログ確認のため、**60秒**保持した後に自動クローズ

## 🛠 動作環境・準備
- **言語**: Python 3.13+
- **環境管理**: `uv` (高速パッケージマネージャー)

### 持ち運ぶべき必須ファイル (Git管理対象)
家や別のPCで開発・実行を引き継ぐ際は、`config.ini`・`state/`・`Downloaded_PDFs/`・`Extracted_Pages/` 以外の
ソースファイル一式（`*.py`, `kouseikyoku_patterns/`, `pyproject.toml`, `uv.lock`, `*.bat` など）を移動させてください。

> ⚠️ **注意 (`.gitignore` 推奨対象・設定済み)**
> セキュリティおよびデータ肥大化防止のため、以下はGitに含めないでください（`.gitignore`済み）。
> - `config.ini` (自院名などの秘匿情報が含まれるため。`config.ini.example` はテンプレートなので対象外)
> - `.venv/` (ローカル仮想環境)
> - `state/` (プロファイルごとの更新チェック記録。旧 `previous_link_*.txt`)
> - `Downloaded_PDFs/`, `Extracted_Pages/` (ダウンロード・抜粋データ。プロファイルごとにサブフォルダ分け)
